🍔 Projeto Dev Burguer Team
📋 Sobre o Projeto
O Dev Burguer Team é um projeto colaborativo desenvolvido como parte da formação DevClub, focado no treinamento de práticas essenciais para o desenvolvimento em equipe. Esta iniciativa simula um ambiente profissional real, permitindo que os desenvolvedores apliquem e aperfeiçoem habilidades de colaboração fundamentais para o mercado de trabalho.

🎯 Objetivos
Desenvolver habilidades de trabalho em equipe
Aplicar práticas de desenvolvimento colaborativo
Simular um fluxo de trabalho profissional
Construir uma aplicação completa (backend e frontend)
🛠️ Tecnologias Utilizadas
Backend
Node.js
Express
MongoDB (ou outra base de dados)
Frontend
React
CSS/SCSS
Axios
👥 Práticas de Colaboração
Controle de Versão: Git com branches individualizadas
Code Review: Pull Requests para revisão de código
Integração Contínua: Merges para a branch main
Gestão de Projeto: Jira para acompanhamento de tarefas
Comunicação: Reuniões regulares e atualizações de status
